## Yapılacaklar

1. Her .jsx dosyasının en üstüne `"use client";` satırını ekle
2. Uzantıyı `.jsx` → `.tsx` olarak değiştir (zorunlu değil ama önerilir)
3. Default export olduğundan emin ol (hepsi zaten var)
